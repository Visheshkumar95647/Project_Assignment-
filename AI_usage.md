
# AI_USAGE.md

# AI Usage Report

## Project
**Food Ordering Application**

---

# Purpose

AI was used as a development assistant to improve productivity while ensuring that all generated code, configurations, and documentation were manually reviewed, integrated, tested, and validated.

---

# AI Tools Used

- ChatGPT (OpenAI)

---

# How AI Was Used

## 1. Project Planning

AI assisted in:

- Designing the project architecture
- Organizing frontend and backend folder structures
- Defining development phases
- Planning reusable components and clean architecture

---

## 2. Backend Assistance

AI helped with:

- FastAPI project structure
- SQLAlchemy model guidance
- Alembic migration setup
- JWT authentication implementation guidance
- Password hashing using Passlib
- Exception handling suggestions
- Logging recommendations
- Docker configuration
- API documentation improvements

---

## 3. Frontend Assistance

AI assisted with:

- React component structure
- Redux Toolkit architecture
- Async thunk patterns
- Protected routes
- Role-based routing
- Axios interceptor implementation guidance
- Responsive UI suggestions
- Form validation using React Hook Form
- Tailwind CSS styling improvements

---

## 4. DevOps Assistance

AI provided guidance for:

- Dockerfiles
- Docker Compose
- GitLab CI/CD pipeline
- Azure App Service deployment
- Azure Container Registry integration
- Environment variable configuration

---

## 5. Documentation

AI assisted in creating:

- README.md
- AI_USAGE.md
- Deployment documentation
- Setup instructions
- Project descriptions

---

# Validation Performed

All AI-generated content was manually reviewed before being added to the project.

Validation included:

- Running backend APIs locally
- Verifying frontend functionality
- Testing Docker containers
- Checking API integration
- Testing authentication flow
- Verifying database operations
- Confirming successful Azure deployment
- Reviewing CI/CD pipeline execution

---

# Manual Development

The following activities were completed manually:

- Integrating frontend with backend APIs
- Debugging runtime errors
- Configuring PostgreSQL
- Managing Alembic migrations
- Writing and updating project configuration
- Deploying to Azure
- Configuring GitLab Runner
- Testing application workflows

---

# AI Limitations

AI-generated suggestions were not accepted blindly.

Each recommendation was:

- Reviewed
- Modified where required
- Tested before use
- Adapted to match project requirements

---

# Compliance

No backend APIs were fabricated.

No mock data was used in the final application.

The application uses the implemented FastAPI backend and PostgreSQL database.

---

# Conclusion

AI acted as a development assistant throughout the Software Development Life Cycle (SDLC). All final code, configurations, deployment steps, and documentation were validated by the project author before submission.
